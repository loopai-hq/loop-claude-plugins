# Maintainers

Maintainers review and merge pull requests, cut releases and handle security
reports. Contact them through issues, pull requests, or `security@loopai.com`
for anything security-related (see [SECURITY.md](SECURITY.md)).

| GitHub | Role | Areas |
|---|---|---|
| [@bhavathi-loop](https://github.com/bhavathi-loop) | Maintainer, code owner for every path | `oncall`, `engg`, `platform-engineer`, CI, releases |

How to become a maintainer, and how decisions are made, is in
[GOVERNANCE.md](GOVERNANCE.md).
